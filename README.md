# My Fullstack App

This project is a fullstack application built with React for the frontend and Express for the backend. It demonstrates how to create a simple web application with a RESTful API.

## Project Structure

```

├── backend

│   ├── package.json

├── frontend
│   ├── src
│   │   ├── App.tsx
│   │   └── index.tsx
│   ├── public
│   │   └── index.html
│   ├── package.json

```

## Getting Started

To get started with this project, you need to set up both the backend and frontend environments.

### Prerequisites

- Node.js (version 14 or higher)
- npm (Node Package Manager)

### Backend Setup

1. Navigate to the backend directory:
   ```
   cd backend
   ```

2. Install the dependencies:
   ```
   npm install
   ```

3. Start the backend server:
   ```
   npm start
   ```

### Frontend Setup

1. Navigate to the frontend directory:
   ```
   cd frontend
   ```

2. Install the dependencies:
   ```
   npm install
   ```

3. Start the frontend application:
   ```
   npm start
   ```

## Usage

Once both the backend and frontend servers are running, you can access the application in your web browser at `http://localhost:3000`.
